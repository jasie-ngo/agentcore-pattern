1Folder structure

One Runtime serves one use case at a time. Each use case is a folder of forms; the engines that read those forms are shared.

3Blueprint tool: retrieval

One handler reads DynamoDB for every retrieval tool in every use case. It has no table or field names in it — it reads them from TOOL_CONFIG, which is your YAML entry.

Framework codelambdas/blueprints/retrieval/handler.py
# Settings come from the generated manifest via CDK
CONFIG = json.loads(os.environ.get("TOOL_CONFIG", "{}"))
table = boto3.resource("dynamodb").Table(os.environ.get("TABLE_NAME", ""))

def _list(event: dict) -> str:
    flt = CONFIG["filter"]
    value = event.get(flt["key"]) if flt.get("from_input") else flt.get("value")
    query = {
        "IndexName": flt["index"],
        "KeyConditionExpression": Key(flt["key"]).eq(value),
        "ScanIndexForward": not flt.get("newest_first", False),
    }
    where = None
    for field in flt.get("where", []):
        if event.get(field) in (None, ""):
            return _dump({"found": False, "error": f"{field} is required"})
        condition = Attr(field).eq(event[field])
        where = condition if where is None else where & condition
    if where is not None:
        query["FilterExpression"] = where
    items = [_project(i) for i in table.query(**query).get("Items", [])]
    return _dump({"found": bool(items), "count": len(items),
                  CONFIG.get("result_key", "items"): items})

def _project(item):          # only hand back `returns` fields
    fields = CONFIG.get("returns")
    return {f: item.get(f) for f in fields} if fields else dict(item)

4Blueprint tool: record_write

Creates records with input checks, defaults, derived fields, timestamps and optional SNS notification. Deterministic ids make re-deliveries idempotent.

Framework codelambdas/blueprints/record_write/handler.py
def _make_id(item: dict) -> str:
    spec = CONFIG.get("id") or {}
    sources = spec.get("from") or []
    values = [item.get(f) for f in sources]
    if sources and all(v not in (None, "") for v in values):
        # same inputs → same id → no duplicate records
        digest = hashlib.sha256("\n".join(map(str, values)).encode()).hexdigest()
        body = digest[: spec.get("length", 16)].upper()
    else:
        body = uuid.uuid4().hex[: spec.get("length", 8)].upper()
    return f"{spec.get('prefix')}-{body}"

def _build_item(event):
    ...                     # inputs → coerce → required check
    for field, value in (CONFIG.get("defaults") or {}).items():
        item.setdefault(field, value)
    item.update(CONFIG.get("set") or {})
    _validate(item)         # rules: min / max / one_of / max_length
    for field, rule in (CONFIG.get("derived") or {}).items():
        source = item.get(rule["from"], Decimal(0))
        item[field] = rule["then"] if source >= Decimal(str(rule["gte"])) else rule["else"]

def handler(event, context):
    mode = CONFIG.get("if_exists", "new_record")
    ...  # put_item with attribute_not_exists → "created" | "existing"

def classifier_spec(name, *, labels, flags=None, fields=None,
                    multi_label=True, fallback="other", **kwargs):
    ids = [str(l["id"]) for l in labels] + [fallback]
    label_type = _literal(ids, ...)     # Literal["card_dispute", ...]

    # 1. output schema, generated from the form
    model_fields = {
        "labels": (list[LabelModel], ...),
        "primary_id": (label_type, ...),
        "needs_triage": (bool, ...),
    }
    for flag, description in (flags or {}).items():
        model_fields[flag] = (bool, Field(description=description))
    model = create_model(f"{_pascal(name)}Result", **model_fields)

    # 2. system prompt, generated from the same form
    prompt = _prompt(
        _header(kwargs, "Classify the message."),    # context + task
        "Choose from this fixed set of labels:\n" + taxonomy,
        "Rules:\n" + _bullets(rules),
        "Also set these flags ...:\n" + _bullets(flag_rules),
        _footer(kwargs),   # extra_instructions, "never invent facts"
    )
    return model, prompt, kwargs

def classifier(**kwargs):
    return _from_spec(classifier_spec, kwargs)
    # → factory.build_agent(structured_output_model=model,
    #                       system_prompt=prompt, gateway=...)

6Decision tables

Business rules as data: no model involved, so the same inputs always give the same decision, and the business can review the rules without reading code.

Framework codeapp/_shared/decision_table.py
def evaluate(table: dict, inputs: dict) -> dict:
    values = _coerce(inputs, table.get("inputs") or {})
    matches = []
    for i, rule in enumerate(table.get("rules") or []):
        if all(_holds(values.get(f), cond, values)
               for f, cond in (rule.get("when") or {}).items()):
            match = {**rule["then"], "rule_id": rule.get("id")}
            if table.get("hit_policy", "first") == "first":
                return {**match, "inputs": values}
            matches.append(match)        # collect
    if not matches:
        return {**table["default"], "rule_id": "default", ...}
    return {**matches[0], "matches": matches,
            "rule_ids": [m["rule_id"] for m in matches], ...}

# operators: eq ne lt lte gt gte in not_in is_empty same_as

9Order of work for a new use case

Start from the agents, work out to the tools and the Gateway, then the rules and deployment.

  1. config.yaml — agent logic

    Models, blueprint specialists (fill in each form), the coordinator's step-by-step prompt, the delegate orchestration. While writing the coordinator, list every tool the flow needs.

  2. Check the blueprint tools

    For each needed tool: reading records → retrieval; creating a record → record_write; already exists in another use case → uses:. Whatever is left becomes custom.

  3. gateway_tools.yaml — reference them

    tables: (created for you, or existing:), uses:, and one tools: entry per blueprint or custom tool.

  4. lambdas/<use_case>/<tool>/ — custom tools only

    handler.py returning json.dumps({...}) + schema.json; declare environment, tables, permissions in the form.

  5. uv run --project app python scripts/build_tools.py

    Generates schemas, manifest and the Gateway targets in agentcore.json. Extra infra → infra-construct.ts; Gateway limits → Cedar in agentcore.json.

  6. decisions.yaml + tools.py

    The deterministic rules, bound as a tool (two lines). Match the table's inputs to the agents' output fields. @tool code only for ordered side effects.

  7. ingestion.yaml + seed_data.yaml + sample_emails/

    Email clean-up and the ID regex; one seed record and one sample per scenario.

  8. Test locally

    sca dev --config app/<use_case>/config.yaml; add decision-table and config tests; python -m pytest tests/.

  9. Switch on and deploy

    USE_CASE = "<use_case>" in app/main.py → ./deploy.sh <region> → scripts/seed_tables.py <use_case> → upload to claims-inbox/<use_case>/.

The rule of thumb Describe it in a form if you can; write code only for real business logic that no form expresses.
