# Client template

Copy this folder to `clients/<client-name>/`, then follow `clients/README.md`.

- `sources/`  put the client's documents here. Contents are not committed.
- `pack/`     put `vocabulary.yaml` and one `.feature` file here. The compiler writes `manifest.json` and `compiled/`.

The template is deliberately empty: a blank vocabulary would be a pack that looks valid and means nothing.
