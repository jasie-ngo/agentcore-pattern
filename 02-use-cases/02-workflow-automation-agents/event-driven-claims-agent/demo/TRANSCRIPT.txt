== 3. The pack ==
   [REAL: compile, Cedar evaluation, the Strands agent loop.  MOCKED: the model (scripted, no LLM), the tools (stand-ins) and the approval record (a labelled test fixture: no real approver, not signed)]
  > Plain-language rules, plus a vocabulary that says what the words mean.
    Given the tool "send_notification" is never permitted
    Given the tool "lookup_policy" is permitted
    Given the tool "create_claim" is permitted only when status is "pending_review" and decision is "escalated"
  > A deterministic compiler (no LLM) turns them into Cedar.
    forbid (principal, action == Action::"notification___send_notification", resource);
    permit (principal, action == Action::"policy-lookup___lookup_policy", resource);
    permit (principal, action == Action::"list-pending-claims___list_pending_claims", resource);
    permit (principal, action == Action::"human-review___request_human_review", resource);
    permit (principal, action == Action::"create-claim___create_claim", resource)
    when { context.input has status && context.input.status == "pending_review" && context.input has decision && context.input.decision == "escalated" };
  > Now an agent tries three calls. The model's choices are scripted; the policy check is the real one.

== 5. Not done yet ==
   [SLIDE: stated plainly]
    - Approvals are not signed. Today an approval is a JSON record anyone could forge.
    - The rules directory is not packaged with the app container.
    - Only one agent can carry the tool policy: it denies every tool it does not name.
    - The member memory identity is unresolved. Effective dates are checked against today, not the case date.
    - The routing-gate vocabulary is still specific to the first client. Only the tool boundary is extracted.
    - The framework leans on an alpha, single-maintainer composition library, unpinned in the repo.
    - No real second client. The health-insurer rules are illustrative, and no health-data threat model exists.
    - No measured delivery saving. We have no baseline, so we claim none.
